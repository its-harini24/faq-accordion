# React Accordion FAQ

A simple and responsive Accordion FAQ application built with React. Users can click on a question to expand its answer and click it again to collapse it.

## Features

- Expand and collapse FAQ items
- Only one FAQ is open at a time
- Clean and responsive UI
- Built using React Hooks

## Concepts Used

- React
- useState Hook
- Event Handling
- Conditional Rendering
- map() Function
- Arrays of Objects

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3

## Project Preview

Click on a question to view its answer. Click the same question again to collapse it.

## Installation

```bash
git clone https://github.com/its-harini24/faq-accordion.git
cd faq-app
npm install
npm start
```
